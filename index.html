What's Inside

Everything you need
to detect financial fraud

🤖

AI Detection

Ensemble of six trained models — Logistic Regression, Random Forest, Decision Tree, SVM, Isolation Forest, and K-Means — vote on every transaction.

🔔

Real-Time Alerts

Instant fraud alerts with Low, Medium, and High severity levels, sound notifications, and a full resolution audit trail.

📊

Analytics Dashboard

Live stat cards, fraud trend charts, risk distribution histograms, and period-over-period comparisons — all in one view.

🛡️

Secure System

bcrypt password hashing, Fernet-encrypted account numbers, session timeout, and account lockout after failed attempts.

📁

Bulk CSV Import

Upload tens of thousands of transactions at once. Supports 100,000+ rows with background processing so the UI stays responsive.

⚙️

Admin Control

Full user management, AI threshold controls (60–90%), system activity logs, and one-click database backup and restore.

Process

Up and running in minutes

Step 01

Import Transactions

Add transactions manually or bulk-upload a CSV file. Account numbers are encrypted automatically.

→
Step 02

Run AI Detection

The ensemble model scores every transaction 0–100. Anything above your configured threshold is flagged as fraud.

→
Step 03

View Alerts & Reports

Review flagged transactions, resolve alerts, and export professional PDF or Excel reports with date filters.
